# 安全与留存（security-and-retention）

## 最小化处理

| 数据 | 处理方式 |
|---|---|
| 身份证件号 | 只保存受控比对摘要（sha256(项目盐 + 完整号码) 前 16 位）与展示掩码 `1101**********7258`；完整号码不写入结果、日志、异常堆栈 |
| 手机号 | 规范化值为受控摘要（`P` + sha256 前 16 位）；展示掩码 `138****0001` |
| 固定电话 | 企业联系方式，保留原文（比对键去分隔符） |
| 银行账户 | 本期不提取、不保存 |
| 统一社会信用代码 | 非个人敏感信息，原文展示 |

- `project.yaml` 的 `id_digest_salt`（项目内固定）保证：同项目可重复运行（T12 逐字段一致）、
  跨项目摘要不可直接反查。**盐本身绝不写入任何输出**（序列化层 exclude，只写指纹
  `id_digest_salt_fingerprint`）。
- 报告渲染后自动运行脱敏扫描；命中完整证件号/手机号即失败退出（exit 3）。

## 凭据与访问

- 外部渠道仅保留中国政府采购网（不需要账号密码 —— **永远不要向用户索要**）；
  内部仅保留富奥 SRM（账号密码仅运行时内存使用）。信用中国、军队采购网、
  公开工商信息、司法公开信息渠道已于 2026-09-09 移除。
- 富奥 SRM 为内网系统：如需在线访问，账号密码由用户在会话中临时提供，
  仅存于进程内存，不得写入 Skill、project.yaml、输出、日志、异常信息；
  推荐改用授权导出文件导入。
- 不提交浏览器会话、Cookie、密码、网页抓取密钥至 Skill 或测试样本。
- 外部查询默认只读；禁止绕过验证码、登录、反爬、付费墙或访问频率限制。

## 保留与处置

- 默认 `retention_policy: project_local`：全部中间产物与报告保留在项目目录
  `output/` 下，由项目数据权限系统管理。
- 原始受控证据（含完整证件号的原始标书）由项目数据权限系统保存，Skill 不复制。
- 报告交付前按 `report-spec.md` 执行脱敏检查；含敏感信息的原始项目目录
  不得作为 Git 测试夹具（测试一律使用 `tests/fixtures/` 中程序生成的虚构数据）。

## 审计与可追溯

- 每个文件记录 SHA-256；每条证据记录来源定位、采集时间、提取方法、置信度、强度；
- 每次查询记录渠道、主体键、状态、时间、适配器版本；
- 运行标识（run_id）+ 工具/规则版本写入报告与结构化结果，支持复核重放；
- 相同输入与规则版本重跑，结构化结果除运行标识/时间外逐字段一致（T12）。

## 上线前检查清单（真实数据）

业务、合规、信息安全共同确认（方案 9.4）：

1. 采购文件的资格/否决条款映射与适用时间截点；
2. 每个外部渠道的访问授权与留存要求；
3. SRM 的数据字段、权限与法律/业务授权；
4. 保存期限、加密位置、访问角色和审计日志；
5. 报告模板中的责任说明和人工审核签字流程。

未完成确认前，仅可运行脱敏演示或离线证据导入模式。
